# Tests

- `ContainerMCPCoreTests`: the policy and the tool surface against `FakeBackend`, which records every call that reaches it. Files are grouped by the numbered limits in the top-level README. `MCPProtocolTests` and `ToolStandardTests` cover the files copied unchanged from the owner's other servers (the protocol, and the tool standard's limits, notices and guard), `BoundsTests` the edges of the tool standard for this server's own tools (pages, logs, exec output, descriptions, limits and deadlines), and `ProgressNotificationTests` the progress notifications as a client receives them. Run with `swift test`.
- `ContainerMCPIntegrationTests`: `OutputCollectorTests`, which need no service, and one live test that calls every tool against the real container service. It runs only with `CONTAINER_MCP_INTEGRATION=1`, creates only labelled `container-mcp-it-…` resources and removes them.
